# OFF_DESIGN_MAPS_AND_NOZZLES.md — Approved D01=B and D02=B

**Decision status:** LOCKED, 2026-11-01. D01=B: derive off-design N1/N2 from validated component maps; D02=B: user-adjustable effective nozzle throat area, reflected in both actual displayed geometry and solver. **Evidence status (2026-11-05):** Five source-pinned pyCycle map tables have been imported and interpolation tested, but engine-specific scaling and absolute-RPM calibration are NOT independently validated. A simplified *unmapped* solver now matches turbine/compressor shaft work against nozzle-derived flow with branch diagnostics, and convergent nozzle choking uses variable-heat-capacity energy balance. Original SolidCraft nozzle lip and petal vertices follow accepted hypothetical geometric apertures; the exported GLBs pass a bounded 17-case internal mesh audit, but full actuator clearances and measured engine geometry remain unverified. Coupled **mapped** off-design closure is not implemented. This document defines the remaining acceptance contract; see [Digital Twin Evidence](../validation/DIGITAL_TWIN_EVIDENCE.md).

## 1. Architecture consequence
The original steady-state station-based energy balances remain necessary but are **insufficient** for uniquely identifying shaft rotational speeds or off-design flow. Add design-point calibration, shaft-speed-dependent maps, corrected flows and speeds, flow-capacity constraints, variable nozzle-area geometry, and a coupled nonlinear engine matching problem. TJ-1 has one compressor, one turbine, one shared shaft; TF-2 has fan, LPC, HPC, HPT, LPT, independently matched LP and HP spools, separate core and bypass streams and two adjustable effective exit/throat controls. The product remains a **steady-state off-design** simulator; no transient spool-inertia or startup dynamic prediction is added by D01.

## 2. Map sourcing, validation, and credibility
Candidate public and independently reproducible technical baseline sources:
- NASA T-MATS source and nonproprietary default maps: https://github.com/nasa/T-MATS ; example high-bypass JT9D model setup https://github.com/nasa/T-MATS/blob/master/Trunk/TMATS_Examples/TMATS_Run_Example.m ; consult dataset-specific map source, conditions, calibration and license. T-MATS is Apache-2.0 per repository; metadata and file license are to be verified before redistributing individual map tables.
- OpenMDAO pyCycle: https://github.com/OpenMDAO/pyCycle ; mapped two-spool separate-exhaust example https://github.com/OpenMDAO/pyCycle/blob/master/example_cycles/high_bypass_turbofan.py ; compressor map implementation https://github.com/OpenMDAO/pyCycle/blob/master/pycycle/elements/compressor_map.py . Independently check repository version and data/license before bundling any numbers.
- NASA T-MATS off-design example research and technical calibration reference: https://ntrs.nasa.gov/api/citations/20150000858/downloads/20150000858.pdf . For model/mapping theory see https://ntrs.nasa.gov/api/citations/20070018165/downloads/20070018165.pdf .
- **Do not use restricted C-MAPSS40k distribution** as a free, publicly redistributable source without explicit rights: https://software.nasa.gov/software/LEW-18624-1 . C-MAPSS simulation output data alone do not imply availability of underlying component maps.

**Validation tiers (all explicit):** (1) source identity, license/right-to-redistribute and raw file hash; (2) map definition and axis units, corrected parameter conventions, interpolation fidelity, topology of feasible map, source test points; (3) numerical replication of the source reference's design and at least three independent off-design points over a bounded envelope, with matched property assumptions; (4) speed-scaling evidence in **physical rpm**, including reference design speed and correction convention for the chosen generic reference. If (4) is unavailable, label RPM as **not validated/unavailable** and keep D01 blocked; never silently substitute normalized animation as final achievement. A generic modeled engine may report **model-predicted, reference-calibrated RPM**, not actual measured RPM of an identifiable OEM engine.

Map ingestion may run offline in free tooling (e.g. Python for validation scripts, Blender for geometry) without requiring MATLAB/Simulink at runtime; browser delivery is offline-compatible typed data and TypeScript/Worker numerical solver. Any source tool requiring licensed MATLAB is **reference-only**, not a dependency of the free production site. Export validated map tables into a versioned JSON/binary representation with exact units, source ID/hash, scaling and range.

## 3. Mathematical map contracts
For compressor/fan/LPC/HPC: axes include speed line `Nc` and independent operating-line parameter (e.g. `Rline`); outputs `Wcorr, pressureRatio, isentropicEfficiency`; optionally stable operating-boundary metadata but no quantitative surge margin until separately verified. For turbine: `Nc`, expansion ratio and optional other declared map axes -> corrected flow, efficiency, constrained to feasible region. Distinguish static/total conventions.

**Typical corrected quantities** for reference `Tref, Pref`:
`Ncorr = Nactual / sqrt(Tt_in/Tref)`; `Wcorr = mdot * sqrt(Tt_in/Tref) / (Pt_in/Pref)`. Document whether raw source map uses nominal/percent/rpm and whether source scaling adds a factor. At runtime, solver computes **Nactual** from mapped/corrected speed and corrected inlet temperature, not from visual rotor rate.

Calibration at design: map speed, flow, PR and efficiency scale factors must preserve physical units and a documented target design point. Use standard pressure-ratio scaling around 1 if source warrants, then apply bounded interpolation; derivatives/continuity and extrapolation policy documented. No extrapolation by default; out-of-map points rejected with a map-boundary reason. Source map scaling may not reproduce actual real-engine surge/stall boundaries; do not describe generic maps as OEM validated.

## 4. Off-design unknowns, equations and degrees of freedom
**TJ-1:** solve compressor map operating line, physical shaft speed `N_TJ`, turbine expansion ratio, station mass continuity, compressor/turbine shaft power, fuel/TIT schedule, nozzle flow capacity under user-selected `A8_eff`. Choose enough independent unknowns for residual count; do not additionally hard-force the design-point PR, efficiency and mass flow as independent off-design constraints.

**TF-2:** unknowns include `N_LP`, `N_HP`, fan/LPC/HPC map line parameters, HPT/LPT flow/expansion ratios and appropriate core/bypass flow variables, with consistency at splitter, cross-component flow matches, separate HP/LP shaft balances and both nozzle flow closures. **No universal list of exactly N independent unknowns is assumed until topology and maps are selected**; produce the explicit equation/unknown Jacobian incidence matrix in the implementation mathematical derivation and verify full rank near the design point.

At **design point**: user-editable pressure ratios, efficiencies, bypass ratio and inlet mass flow define/sweep hypothetical design configurations, subject to map rescaling and geometry consistency. At **off-design point**: pressure ratios, efficiencies, actual shaft speed and incoming mass flow generally become solver outputs, not simultaneously independent sliders. Throttle drives a bounded TIT schedule; altitude/Mach/ambient and explicit adjustable nozzle effective areas are control inputs. Separate **Design / Off-design** control modes in the UI; show which parameters are locked, recalibrated or computed when switching modes. Never silently contradict approved Q25/Q55/Q115: advanced parameters remain editable in appropriate design/configuration mode; each edit creates a new labeled design configuration with recalibrated map scales and tested feasibility. If a desired input cannot be held constant in off-design, explain why and offer an appropriate design-mode workflow.

Iterative solver: bounded Newton/trust-region or safeguarded nonlinear solve with residual scaling, Jacobian/conditioning diagnostics and recovery; use continuation from prior converged operating point only with branch tracking. Detect negative or nonphysical state, outside-map domain, unmatched nozzle capacity, zero/negative thrust for TSFC, infeasible TIT/mass-flow, singular Jacobian, and nonconvergence. Last valid result stays clearly marked stale. Prevent false off-design predictions from a map that has unverified absolute RPM scale.

## 5. D02: effective throat geometry and physical flow
Three explicit user controls: `TJ A8_eff`; `TF core A8_eff`; `TF bypass A18_eff`. Each has baseline, bounded range, unit conversion, reset and change history. If a model instead exposes exit area separately, name it separately; do **not** equate effective throat area to geometric exit area when discharge coefficient or nonconvergent geometry changes the relation. Model:
`A_eff = C_d * A_geom_throat` for documented discharge coefficient and reference geometry. Use chosen `A_eff` as a nozzle flow-capacity boundary, not an adjustable multiplicative thrust cosmetic factor. Distinguish `A_throat`, `A_exit`, flow coefficient and external pressure thrust term.

For an illustrative convergent nozzle with baseline exit at throat, `A_exit = A_geom_throat` must be consistent with selected geometry. If model adds separate exit area, make its influence explicit. Under unchoked conditions compute isentropic/efficiency-adjusted exit solution with appropriate boundary pressure; under choked conditions enforce sonic throat and pressure-thrust. Couple nozzle mass capacity `mdot_map(Pt,Tt,A_eff)` to shaft/component maps and incoming mass flow for steady-state matching. Nozzle area changes influence engine matching, thrust and potentially RPM **through the solver**; reject requests outside the valid map/geometric envelope. Never make solver silently change A to satisfy the user.

**3D synchronization:** each nozzle must be a *parametrically deformable* mechanical assembly with throat ring(s), wall segments and rim; change visible geometry with the exact same validated area result. For reference circular annulus, `A_geom = pi*(r_outer²−r_inner²)`, with stable centerbody and r_outer adjusted within mechanical bounds; if more general geometry is used, derive the appropriate area relation. If discharge coefficient changes but shape does not, show effective-flow-area vs geometric-area distinction in inspector. Update anchors/measurement overlays to reflect geometry, including dimension callout and area label. Do not merely scale an entire downloaded mesh, disconnect the shaft, move outer shell nonsensically or fake nozzle resizing with color.

**Atomic update:** store validated `nozzleAreaRequest` in canonical SI; worker returns converged `effectiveAreaAccepted`, `geometricThroatArea`, `exitArea`, `nozzleState`, `stationFlow`, `RPM`, `thrust`; renderer uses accepted result snapshot ID. While computation is in-flight show pending intent/ghost preview (if useful), but **do not present committed geometry** with old numerical readouts as simultaneously valid. Failed solve restores previous accepted mesh + readouts or labels any ghost as unvalidated. Engine switching resets incompatible nozzle areas with explicit user notice.

## 6. Scene and telemetry requirements from D01
TJ turbine and compressor share one shaft and actual model-predicted speed; TF fan/LPC/LPT rotate under LP speed, HPC/HPT under HP speed; stators static. Display calculated `N_TJ`, `N1/LP`, `N2/HP` in **rpm** and optional percent-of-reference design speed; display source/map ID, uncertainty/validation note. Rendering angular speed must be visually aliased/safely bounded for browser sampling; visible angular velocity can be slowed while numeric actual RPM remains true and clearly distinguished. Never connect UI time-step to solver physical time (steady-state only).

## 7. Acceptance and fallback rules
- License-audited published dataset and source file plus independent ingestion fixture for each compressor/turbine (TJ C/T; TF fan/LPC/HPC/HPT/LPT). Reference calculations for design plus representative off-design points match within **tolerances established before implementation**. If map source is incompatible with user-selected architecture or unavailable, scientific acceptance fails; do not silently replace user-approved D01=B with invented maps or illustrative RPM.
- At each valid operating point, all mapped compressor/turbine PR/eff/flow correlate with station thermodynamics and independent shaft balance. Confirm map range, corrected/actual speed, rotor grouping and dual-nozzle flow. Numerical conservation tests around choking and area changes, including cases where solver rejects an infeasible nozzle setting.
- Test selected area to actual mesh throat area (in SI) at multiple values and LODs; verify signed flow path and independent core/bypass geometry; prevent clipping/interference and material/normal tearing. Monitor stale worker outputs and out-of-order scene updates.
- If absolute RPM or published map fidelity cannot be scientifically validated, **fail D01 release gate**, document blocked, and offer no fictional success claim. The platform may still build a visual prototype, but must not be shipped as meeting approved D01.

These are strong leads for independent validation, **not validation completed**. **Known restricted source:** NASA C-MAPSS40k public catalog restricts access; do not rely on it as free project data. **Unverified:** actual map datasets, calibrated RPM scales, map licensing of selected raw tables, independent reference agreement, nozzle area-to-geometry mechanism, numerical conditioning, and browser speed.
